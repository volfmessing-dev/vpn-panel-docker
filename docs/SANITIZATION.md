# Состав публичной версии

Экспорт создан из списка исходных файлов backend/frontend. История исходного репозитория не переносится.

Исключены: .env, SSH/WireGuard ключи, htpasswd, базы/дампы, volumes, диагностика, RouterOS экспорты/backup, персональные документы, production deploy-скрипты и workflow, локальные IDE-файлы, старые сетевые конфигурации и bypass-списки.

В тестах адреса узлов заменены адресами документации 192.0.2.0/24, 198.51.100.0/24 и 203.0.113.0/24; пользователи и имена узлов заменены шаблонами. Встроенные bypass-домены удалены, CIDR читаются только из локальной настройки BYPASS_CIDRS. Пулы/LAN/клиентская подсеть заменены новыми универсальными примерами. Служебная таблица маршрутизации переименована в vpn_panel_exit.

Пароль панели задаёт установщик, пароль базы генерируется случайно. Никакие действующие учётные данные не поставляются. .gitignore и .dockerignore исключают локальные секреты и кэши. Примеры public DNS, loopback, default route и private CIDR — технические шаблоны, а не адреса прежних серверов.

Рабочая производственная система не изменяется. GitHub-аккаунт владельца присутствует только в публичной ссылке клонирования. Публикация этой версии не удаляет данные из других репозиториев или их истории.
